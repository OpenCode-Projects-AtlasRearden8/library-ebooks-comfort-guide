# Device-by-Device Checklists

Everything you need, per device, in first-run order. Each checklist assumes the same two prerequisites: **your library card number + PIN** (chapter 01) and a Wi-Fi connection. Checkbox marks are for printing — this chapter is the one page worth keeping on the fridge. Details behind each step live in the chapter(s) noted at the end.

## Phone (iPhone or Android)

*The most common setup — start here even if you'll add other devices later.*

- [ ] Install **Libby** from your app store (chapter 02).
- [ ] Open Libby → **I Have a Library Card** → find your library by city/ZIP → enter card number and PIN.
- [ ] Borrow any book that says **Borrow!** (filter **Available Now** to find them fast).
- [ ] Tap the middle of a page → adjust **text size** and enable **Include accessibility sizes** (chapter 09).
- [ ] Download the borrow for offline use (train/flight/basement insurance).
- [ ] (Optional) Install **hoopla** and register with the same card — check your monthly instant-borrow allowance (chapter 03).
- [ ] (Optional, Kindle owners) Set Libby's default reading preference to **Kindle** (chapter 04).

> *One gotcha: the loan clock starts at borrow, not at first open. Open the book today.*

## Tablet (iPad, Android tablet, or Fire tablet)

*Best all-round couch reading: bigger page, same app, same account.*

- [ ] Install Libby (iPad/Android tablets: normal stores; **Fire tablets: Amazon Appstore**).
- [ ] Sign in with the same card — loans, holds, tags, and reading positions sync over automatically.
- [ ] Test both directions of sync: read two pages on your phone, check the position here.
- [ ] Adjust text/theme for the bigger screen (chapter 09).
- [ ] For magazines, a tablet is *the* device — Libby's magazine reader shines here (chapter 07).
- [ ] Turn on KIDS mode in hoopla if kids share this tablet (chapter 03).

## Kindle e-reader (Paperwhite/Oasis/system vintage)

*The U.S. Kindle flow; no Libby app on Kindle e-readers themselves.*

- [ ] Connect the Kindle to Wi-Fi and register to your Amazon account (Kindle: Settings → account).
- [ ] On your phone (or at `libbyapp.com`) — borrow the ebook in Libby.
- [ ] **Shelf → Loans → Read With... → Kindle** → sign into Amazon (same account!) → **Get Library Book**.
- [ ] On the Kindle: let it sync; the cover then appears on the home screen.
- [ ] Set the default to **Kindle** in Libby's settings so future borrows route themselves (chapter 04).
- [ ] When a loan ends or misbehaves, use **re-delivery** from Amazon **Content & Devices** (chapter 04) — this fixes most Kindle weirdness without support calls.
- [ ] Loan ends on schedule; Amazon removes the book at next sync. Nothing overdue, ever.

## Kobo e-reader

*Cleanest e-ink library experience — no phone step needed (U.S./Canada).*

- [ ] Check your model supports built-in Libby/OverDrive (recent Clara/Libra/Elipsa families; Settings → OverDrive).
- [ ] On the Kobo: Settings → OverDrive → sign in with your **library card**.
- [ ] Browse (**Discover → OverDrive/Libby**) → borrow → the book lands in My Books.
- [ ] Kobo syncs borrowed titles when Wi-Fi is on — keep on Wi-Fi after borrowing.
- [ ] If a specific book refuses to appear: some titles are device-incompatible and *audiobooks/magazines never appear on Kobo* (chapter 09) — read those in the Libby app instead.
- [ ] Comfort: font size/family/weights live in the reading menus (chapter 09).

## Laptop or desktop (Windows, Mac, Chromebook)

*No installs at all — everything runs in the browser.*

- [ ] Open `libbyapp.com` and sign in with your card (the identical Libby UI).
- [ ] Borrow and read ebooks there; position re-syncs with your phone.
- [ ] For hoopla: `hoopladigital.com`, same card, same allowances.
- [ ] Kindle route: the borrow → Read With Kindle flow works from any computer's browser.
- [ ] Reading comfort: browsers ignore app text-size settings — zoom with Ctrl+/Cmd+= for the pages themselves (chapter 09).

## Smart TV (hoopla)

*hoopla only — Libby has no TV app; hoopla's apps sit on many TV platforms.*

- [ ] Install the **hoopla** app on your TV's app store (availability varies by brand/platform).
- [ ] Sign in with the same hoopla account (email/password) you use elsewhere.
- [ ] Great fits: kids' shows, the rotating movie shelf, concert films during dinner.
- [ ] Remember the short video loan windows (48–72 hours) — start watching what you borrowed.

## Car (audio anywhere)

- [ ] Pair the phone to Bluetooth/CarPlay/Android Auto per your car's routine.
- [ ] Play the audiobook in Libby/hoopla; use steering-wheel controls and the dash screen.
- [ ] Download the book for offline use *before* the drive (chapter 07) — data dead-zones ruin chapter 14.
- [ ] Sleep timer if you nap in the car (it happens; weird parking lots; respect).

## Old/slow phone rescue

*Borrowed books like to start cheap: a 5-year-old phone in a drawer works fine.*

- [ ] Update the OS as far as it will go, then install Libby (it runs on quite old iOS/Android versions; if the store refuses, `libbyapp.com` in the browser is the fallback).
- [ ] Stream audiobooks rather than downloading if storage is tight.
- [ ] Settings → free space check before downloads (the symptom table's "download stuck" is almost always storage).
- [ ] Airplane mode + downloaded books = the calm reading plan.

## The two-minute family edition

- [ ] One card per person, not shared (chapter 01) — separate holds/queues.
- [ ] Kids' tablet: KIDS mode (hoopla) and/or their own kid card.
- [ ] Card numbers + PINs stored in the parents' password manager, *not* on the kid's device.
- [ ] A printed copy of this page on the fridge for the first week.

That's every device that matters. If a brand-new gadget isn't listed here, the fastest triage is: does it have an app store (install Libby/hoopla), a browser (use `libbyapp.com`), or is it an e-reader (run this chapter's Kindle/Kobo checklists)? One of those three will fit.
